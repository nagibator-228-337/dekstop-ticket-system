# Ticket Support System

A simple ticket support system where clients can create and track support requests without registration, and employees can manage tickets, communicate with clients, and coordinate work internally.

## Purpose
This project is application created to practice WPF, C#, and basic application design principles.

## Key Features
- Ticket creation without user registration
- Ticket tracking via unique access code
- Client and employee messaging
- Internal employee notes
- Ticket assignment and status management

## Technology Stack
- C#
- WPF (.NET)
- Visual Studio


Installation:
1. Download the ZIP file from the Assets section below.
2. Extract all files to a folder of your choice.
3. Double-click 'MyApp.exe' to run the application.
